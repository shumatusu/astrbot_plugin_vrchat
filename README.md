# astrbot_plugin_vrchat — VRChat 助手

[![AstrBot](https://img.shields.io/badge/AstrBot-%3E%3D4.14.6-2d6ef0)](https://github.com/AstrBotDevs/AstrBot)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Version](https://img.shields.io/badge/version-2.0.2-blue)](metadata.yaml)

在聊天窗口里查 VRChat：看自己的资料、查好友、逛世界、翻通知、换虚拟形象，
好友上线或收到新通知时还能主动提醒你。

装好之后，所有功能都从一个指令进入：**`/vrc`**。查询结果会整理成一张深色卡片图片，
绑定成功、操作回执这类一句话的事则直接发文字，不用等图。

> 非官方项目：数据来自 VRChat 官方 API，与 VRChat Inc. 无任何关联。

---

## 它能做什么

- 👤 **账号**：绑定自己的 VRChat 账号，登录态加密保存，不用每次重新验证 2FA
- 🔍 **查询**：查看自己/他人的资料、搜索用户、看世界详情与热门世界
- 👥 **好友**：在线好友、**全部好友（A-Z）**、好友关系状态、加好友/删好友/接受请求
- 🔔 **通知**：查看通知，好友请求可直接用通知里的 ID 接受
- 🏠 **群组**：群组详情与成员列表
- ⭐ **收藏**：分「世界」和「虚拟形象」两类查看，可添加/移除
- 🧍 **虚拟形象（Avatar）**：列出、搜索、一键换装
- 📡 **订阅**：好友上线提醒 + 新通知推送（每 5 分钟检查一次）

一个人一个账号，各用各的凭证，互不干扰；群里多个人同时用也不会串号。

## 安装

**前置条件**

- AstrBot `4.14.6` 或更高版本
- 一个 **OneBot 11** 机器人（AstrBot 的 `aiocqhttp` 适配器，QQ）——本插件在该适配器下开发与验证；
  其他适配器没有专门测过，理论上通用接口能跑
- 一个可用的文转图（t2i）端点 —— 卡片靠它出图，没配也能用，只是所有回复都会变成纯文本

**三步装好**

1. 把整个目录放进 AstrBot 的 `data/plugins/`，目录名保持 `astrbot_plugin_vrchat`
2. 安装依赖（AstrBot 加载插件时通常会自动装）：

   ```bash
   pip install -r requirements.txt
   ```

   `httpx`（网络请求）、`cryptography`（加密保存凭据）、`pyotp`（自动生成 2FA 验证码）

3. 在 WebUI 里启用插件，然后私聊机器人发一句 `/vrc 帮助`

   - 收到一张指令总览图 → 一切正常
   - 只收到一句「请发送 /vrc 帮助 查看完整指令。」→ t2i 没配好，先去看 [常见问题](#常见问题)

## 第一次使用

```text
/vrc 绑定            按提示私聊发送「账号 密码 [2FA密钥]」
/vrc 关于我          确认登录成功，看看自己的资料卡
/vrc 好友            在线好友列表
/vrc 订阅 上线 "名字"  好友上线时提醒你
```

绑定只要一次。之后重启机器人、换设备都不用再验证，除非你主动 `/vrc 解绑`。

## 指令速查

统一入口 `/vrc`（也能用 `/vrchat`）。参数带不带引号都行（`"` `“”` `「」` 都认），
**搜索词里可以有空格**；各种 ID 必须带前缀：`usr_` `wrld_` `grp_` `avtr_` `fvrt_` `frq_`。

### 账号

| 指令 | 作用 |
| --- | --- |
| `/vrc 绑定` | 绑定账号，**请在私聊里用** |
| `/vrc 解绑` | 退出登录并删除本机保存的凭据 |

### 自己与他人

| 指令 | 作用 |
| --- | --- |
| `/vrc 关于我` | 我的资料卡 |
| `/vrc 用户 "usr_..."` | 看某人的资料和好友关系 |
| `/vrc 用户搜索 "关键词"` | 按昵称搜人 |

### 世界

| 指令 | 作用 |
| --- | --- |
| `/vrc 世界` | 热门世界 |
| `/vrc 世界 "wrld_..."` | 世界详情（人数、访问量、收藏数） |
| `/vrc 世界搜索 "关键词"` | 搜世界 |

### 好友

| 指令 | 作用 |
| --- | --- |
| `/vrc 好友` | 在线好友（在线排前面） |
| `/vrc 好友 全部` | **全部好友**，含离线，按名字 A-Z 排序 |
| `/vrc 好友 状态 "usr_..."` | 你俩现在是什么关系 |
| `/vrc 好友 添加好友 "usr_..."` | 发好友请求 |
| `/vrc 好友 取消请求 "usr_..."` | 撤回自己发的请求 |
| `/vrc 好友 删除好友 "usr_..."` | 删好友 |
| `/vrc 好友 接受请求 "frq_..."` | 同意别人的请求（`frq_` 从 `/vrc 通知` 里拿） |

每个人后面的标签：状态（在线 / 可加入 / 询问我 / 忙碌 / 离线）、平台（PC / Quest / WEB），
下面一行写他在哪：`网页端在线`、`在世界中：wrld_xxx:12345`、`离线`。

### 通知 / 群组 / 收藏

| 指令 | 作用 |
| --- | --- |
| `/vrc 通知` | 通知列表，好友请求会带可用的 `frq_` ID |
| `/vrc 群组 "grp_..."` | 群组详情 |
| `/vrc 群组 成员 "grp_..."` | 群组成员 |
| `/vrc 收藏` | 收藏的世界 |
| `/vrc 收藏 角色` | 收藏的虚拟形象 |
| `/vrc 收藏 添加世界 "wrld_..."` | 收藏一个世界（可加收藏组） |
| `/vrc 收藏 移除 "fvrt_..."` | 取消收藏 |

### 虚拟形象（Avatar）

| 指令 | 作用 |
| --- | --- |
| `/vrc 角色` | 我上传的虚拟形象 |
| `/vrc 角色 搜索 "关键词"` | 搜公开形象 |
| `/vrc 角色 选择 "avtr_..."` | 换上这个形象 |

### 订阅

| 指令 | 作用 |
| --- | --- |
| `/vrc 订阅 上线 "名字或 usr_..."` | 好友上线时提醒我（可以用名字） |
| `/vrc 取消订阅 上线 "名字或 usr_..."` | 单独取消某个好友 |
| `/vrc 订阅 通知` | 开 / 关新通知推送 |
| `/vrc 订阅 列表` | 看我现在订阅了什么 |
| `/vrc 取消订阅 全部` | 一键清空所有订阅 |

> 引号里的内容带空格也能识别，例如 `/vrc 用户搜索 "vr chat"`。

## 订阅提醒怎么用

**订阅某人上线**——直接说名字就行，不用记 ID：

```text
/vrc 订阅 上线 "Kirito"
```

- 只有一个叫 Kirito 的好友 → 直接订阅成功，顺便帮你打开通知推送
- 有好几个 → 会列出名字和 ID，让你复制具体的 `usr_...` 再订阅一次
- 一个都没有 → 提示「在你的好友列表中未找到该名字」（只能订阅自己的好友）

**会收到什么**

- 好友从**离线变成在线**时提醒一次（一直在线不会重复刷）
- 开启通知后，新收到的好友请求 / 邀请 / 私信会合并成一条消息推给你

**几个要知道的规则**

- 每 5 分钟检查一次，所以提醒可能有几分钟延迟（这是为了不被 VRChat 限流）
- 刚订阅时不会立刻误报「已上线」，会先记下当前状态
- 切换到别的群或私聊后，要**在新会话里重新发一次订阅指令**，提醒才会跟过去

## 配置项

一般默认值就够用。在 WebUI 的插件配置里改：

| 配置 | 默认值 | 什么时候需要改 |
| --- | --- | --- |
| `allowed_user_ids` | 空（所有人） | 只想让特定的人用这个机器人 |
| `friends_page_size` | 10 | `/vrc 好友` 一页显示几个（`全部` 不受限） |
| `search_page_size` | 8 | 搜索结果一次显示几条 |
| `cache_ttl` | 60 | 查询结果缓存多久（秒），调大更省接口调用 |
| `bind_allow_group` | 关 | 允许在群里绑定账号（不建议开） |
| `warm_up_sessions` | 开 | 启动时检查并恢复已绑定账号的登录态 |
| `enable_subscribe` | 开 | 不想用上线/通知提醒就关掉，省得后台轮询 |
| `subscribe_interval` | 300 | 提醒检查间隔（秒），**最小 300**，调小无效 |
| `favorite_tag_world` | `worlds1` | 收藏世界的默认收藏组，合法值 `worlds1`–`worlds4` |
| `encryption_key` | 空 | 想自己保管加密密钥（留空则自动生成） |
| `request_timeout` | 20 | 网络慢、经常超时的话调大 |
| `max_retry_429` | 2 | 被限流时重试几次 |
| `api_base_url` / `api_key` / `user_agent` | 默认即可 | 只有用代理网关时才需要动 |

## 常见问题

**收到的是一段文字，不是图片？**
t2i 端点没配置或挂了。去 AstrBot 的 WebUI 检查文转图服务；插件在渲染失败时会自动退回纯文本，
日志里会有 `VRChat 卡片渲染失败`。功能不受影响，只是没那么好看。

**登录会过期吗？要反复验证 2FA 吗？**
不会。登录成功后凭据加密保存在本机，之后自动复用；万一失效会自动重新登录（有 2FA 密钥的话
连验证码都自动填）。只有在换机器、换加密密钥或 VRChat 主动踢下线时才需要重新 `/vrc 绑定`。

**发完账号密码后一直让我「重新发送」，或者没反应？**
QQ 的「输入中」状态、纯表情、纯图片、只引用一条消息，这些都会以空消息到达，插件会**默默忽略**
而不是报错——直接发正常文字就行。另外绑定要在**私聊**里做，群里发会被拒绝。

**好友列表里看不到离线的人？**
`/vrc 好友` 只列在线好友；要看全部请用 `/vrc 好友 全部`（按名字 A-Z 排列）。

**好友明明离线，标签却是「可加入」？**
已修复。现在离线一律显示「离线」，只有真正在线时才显示「可加入 / 询问我 / 忙碌」。
网页端在线的会显示「网页端在线」。

**收藏世界报错 / 提示 400？**
收藏组必须是 `worlds1`–`worlds4`（虚拟形象是 `avatars1`–`avatars4`，好友是 `group_0`–`group_3`），
自己填别的名字 VRChat 会拒绝。

**订阅了但没收到提醒？**
先 `/vrc 订阅 列表` 看状态；如果换过会话，重新发一次订阅指令；如果刚订阅，第一条提醒要等下一次
状态变化（每 5 分钟检查一次）。

**能在群里用吗？**
查询类指令群里能用；**绑定/解绑建议私聊**，避免账号密码被别人看到。

## 账号安全

- 每个使用者独立绑定，机器人只会用你自己的凭据查你自己的数据
- 账号密码、2FA 密钥、登录态全部加密保存，日志和报错里不会出现明文
- 随时可以 `/vrc 解绑` 退出登录并删掉本机凭据
- 绑定建议私聊，发完记得撤回含密码的消息
- 本项目不会收集、上传任何账号数据；所有请求都直接发往 VRChat 官方接口
